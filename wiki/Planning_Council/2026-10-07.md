## Minutes

### Maven 3.10 Support for Tycho
- Goal of Maven 3.10 is to ease migration from Maven 3 to Maven 4
- Maven 3.10 particularly uses new resolver from Maven 4
- New resolver is a bit more strict in some situations (e.g., no slash in qualifier allowed anymore)
- Currently three issues with Tycho known (one fixed, one PR, one still under analysis)
- Not clear if someone took a look at compatibility layer for supporting both resolvers in Tycho
  - Agreement that keeping it simple and moving forward to Maven 3.10/4 instead of adding potentially unnecessary configurability should be preferred

### EOL for Older Linux Distros / Supported GLIBC Version
- https://github.com/eclipse-platform/eclipse.platform.releng.aggregator/issues/4080
- Two years ago there was an attempt to increase minimum GLIBC version already, but there were issues filed and with some effort support for the current minimum version was preserved
- Now additional effort for supporting the old version would be necessary again
- No one stepped up to do that so far, thus the way forward is to increase the minimum GLIBC version
  - Will effectively drop support of 6+-year-old operating systems
  - Could also simplify how SWT is built (currently differences between GTK3 and GTK4 that could be dropped, but we would lose opportunity for adopting newer GTK4 API without bumping GTK3 requirements)

### Babel Project
- Proposal to terminate the project: https://www.eclipse.org/lists/technology-pmc/msg14452.html
- Currently, translation bundles from Babel are still available
  - May be valuable for many consumers of the ecosystem
  - Can be consumed from update sites at download.eclipse.org
  - Just added or adapted strings will not be available or inconsistent due to lack of maintenance
- Project termination would make the existing update sites unavailable
  - Would be an unnecessary regression, as preserving those update sites is no effort
- The planning council thus proposes to not terminate the project but rather keep it unmaintained, so that the update sites remain available
- For future maintenance, we already have an [issue on the board](https://gitlab.eclipse.org/eclipse-wg/ide-wg/ide-wg-dev-funded-efforts/ide-wg-dev-funded-program-planning-council-top-issues/-/work_items/43)
  - Infrastructure and setup complexity seems to have been one of the obstacles to maintaining the project
  - Reviving the project should focus on evaluating if another, maintained, and easier-to-host translation service is available
