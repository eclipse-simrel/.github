### WebKit Support on macOS
- WebKit API used by SWT is rather old and long deprecated by Apple: https://github.com/eclipse-platform/eclipse.platform.swt/issues/3486
- WebKit is almost entirely internal to Apple, they may drop legacy API support at any point in time
- In the current macOS 27 beta state it is still available
